# assets\img\ —— 放你自己的图片（输入目录）

这个目录是 **`tools\gen_container.py` 的输入**。把你要播的图放进来 →
跑一条命令 → 生成 `container.bin` → 写进 TF 卡 → FPGA 就能在屏幕上轮播这些图。

## 一、放什么格式？（**不用手动转 BMP**）

支持：`.png` / `.jpg` / `.jpeg` / `.bmp` / `.webp` / `.gif`

**手机照片、微信截图、网上下载的图，原样丢进来就行**，工具会自动：
- 转成 RGB
- 缩放到 **1280×720** 铺满屏幕（默认 `fit`：等比缩放后居中裁剪，不变形）

> 只有当你想要别的处理方式时才需要关心参数：
> `--mode fit`（默认，裁剪铺满）/ `stretch`（拉伸，会变形）/ `pad`（等比缩放 + 黑边）。
> 用 `--mode pad` 能保证**整张图完整不裁切**，代价是可能上下或左右有黑边。

## 二、放几张？

- ★ **上限 8 张**：FPGA 端 `ebm_reader.v` 里 `MAX_IMG = 8`，**放满 8 张正好用满**（超过只显示前 8 张）。
- 建议 **4~8 张**（轮播时长按需调：按键 key3 循环 2s / 5s / 10s / 20s，默认 10s）。
- 放 1 张也行 —— 就是固定显示一张，不轮播。
- **文件名决定播放顺序**（工具按文件名排序），想要固定顺序就命名 `01.jpg`、`02.jpg`……
- 每张图配的音效见 `assets\audio\README.md`（一张图固定配一段音，4 段循环）。

## 三、怎么变成能写进 TF 卡的文件

### 省事做法（推荐）：双击 `scripts\4_write_card.bat`

一条龙做完：检查 Python/Pillow → 把本目录打包成 `container.bin` →
列出全部物理盘让你核对 → 自动申请管理员权限写进 TF 卡。**盘号不对就带参数跑**
（比如 TF 卡是 2 号盘）：`4_write_card.bat 2`

### 手动做法（想自己控制时）

```bash
cd /c/FPGA/billboard_prj
python tools/gen_container.py -i assets/img/ -o container.bin
```

跑完会得到 `container.bin`（图片容器），再用 `write_container.py` 写进 TF 卡：

```bash
pip install Pillow                                            # 只需装一次
python tools/write_container.py --list                        # 先查 TF 卡是哪个盘号
python tools/write_container.py \\.\PhysicalDrive2 --input container.bin
```

> 手动跑时**必须用管理员身份的终端**（Git Bash 右键"以管理员身份运行"），
> 否则会报"权限不足"。双击那个 bat 则不用你操心这件事。

## 四、内容有要求吗？——不必是"广告图"，但有两条硬提醒

**内容本身没有任何格式限制**：照片、插画、纯色或渐变图、海报都能播。FPGA 只认像素，
不关心画的是什么。不过本作品叫"应急广告牌"，**答辩演示时内容贴合主题更有说服力**
（疏散指示、安全提示、消防常识、公益宣传这类）。

但有两条**由硬件决定**的构图约束，放图时务必注意：

### ★ 第 1 张图身兼两职 —— 它同时是"应急告警画面"

`play_scheduler.v` 里 `EMERG_ID = 0`（顶层也显式写成 `4'd0`）：
按下 **key4 应急键**，屏幕会立刻切到 **第 0 张图**（文件名排序最前的那张）并锁住不走轮播。

> 所以**第 1 张建议专门放一张醒目的警示/疏散图**，别拿它当普通轮播图随便放。

### ★ 图片最底下 32 行会被字幕盖住

`osd_mixer.v` 会在屏幕**最下面 32 行（1280×720 下是第 688~719 行）**叠一条暖黄字（`#FFD24A`）、
深蓝黑底（`#101828`）的**横向滚动字幕带**（内容来自 `banner_rom`，不是你的图）。

> **重要内容（LOGO、联系方式、大段文字）不要放在图片最底部**，会被字幕带压住。

### 播放顺序

按**文件名排序**。想要固定顺序就命名 `01.jpg`、`02.jpg`、`03.jpg`……

## 五、为什么要插读卡器？

因为要写的是 **TF 卡的裸扇区**（不是普通文件），
**只有把 TF 卡插到电脑的读卡器上，电脑才碰得到它的扇区**；
板子背面的卡槽只有 FPGA 能读，电脑访问不了。
写完拔卡 → 插回板子背面卡槽 → 上电即可。

> 详细说明见手册 **第 10 步〔做素材〕**；速查卡第 3 节 E 类也有命令；
> 原理链路的图解见 `docs\操作手册-文件总目录与调试环境.md`。
