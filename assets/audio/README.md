# assets\audio\ —— 放你自己的音频源文件（可选）

这个目录是 **`tools\gen_audio_rom.py` 的输入**，放你想替换的音频素材。
（不放也行——不指定文件时，脚本会生成 4 段内置提示音。）

## 一、★ 先看清楚音频是怎么"输入"的

**音频和图片走的是两条完全不同的路**：

| | 图片 | 音频 / 字幕 |
|---|---|---|
| 存在哪 | **TF 卡**里 | **FPGA 片内 ROM**（烧进比特流） |
| 输入方式 | 文件放进 `assets\img\` → 打包 | 生成 `.hex` → 放**五处** |
| 改完还要做什么 | **只要重写 TF 卡**，不用重新综合 | **必须重新综合 + 重新烧板** |
| 从哪出 | 屏幕 | **HDMI 口**（用显示器的喇叭/音箱） |

> 所以音效不是"播放一个音频文件"，而是**事先烧进 FPGA 的一段 PCM 采样**。
> 板子上没有喇叭、也没有 3.5mm 耳机口，声音是跟着 HDMI 信号一起送到显示器的。

## 二、放什么格式

**`.wav`，16bit PCM**（不是 `.mp3`、不是 24bit/32bit）。
- 采样率**不限**（44100 / 48000 / …都行，脚本自动重采样到 48kHz）；
- **立体声会自动混成单声道**（左右取平均）；
- 时长**不限**，但请看下面第三条硬限制。

## 三、★ 硬限制：每段只有约 170 ms

片内 ROM 一共 4 段，**每段固定 8192 个样本 @ 48kHz ≈ 0.171 秒**。

- 你的 wav **长了会被截断**（只取前 0.171 秒）；
- 短了会自动循环填充 + 首尾淡入淡出（防爆音）。

> 所以这个 ROM **是给"提示音效"用的，不是用来放歌的**。
> 想要长音频/背景音乐，得改成从 TF 卡流式读取（当前工程没做，属于扩展方向）。

> **完整规格（格式/声道/采样率/音量/排错表）见 `docs\音频素材规格.md`。**
> 懒人版：把 1~4 个 wav 拖到 `scripts\5_audio_to_bit.bat` 上，它会自动生成 hex + 五处同步 + 重综合 + 出新 bit。

## 四、怎么生成 + 放到哪

```bash
cd /c/FPGA/billboard_prj

# ① 用自己的音频（最多 4 个，按顺序对应音效段 0/1/2/3）
python tools/gen_audio_rom.py -w assets/audio/beep.wav assets/audio/chime.wav \
                               -o audio_rom.hex
#    不足 4 段的，剩下的自动用内置音效补齐

# ② 只想要内置 4 段提示音（默认，什么都不用给）
python tools/gen_audio_rom.py -o audio_rom.hex
```

生成后把 `audio_rom.hex` 复制到 **五个位置**（和图片 hex 同理，TD 按 `.v` 所在目录解析 `$readmemh`）：

```
C:\FPGA\billboard_prj\audio_rom.hex              ← 工程根
C:\FPGA\billboard_prj\src\hdl\audio_rom.hex      ← ★ 综合时真正读这里
C:\FPGA\billboard_prj\src\rom\audio_rom.hex      ← 存档
C:\FPGA\billboard_prj\billboard_Runs\syn_1\      ← 综合运行目录
C:\FPGA\billboard_prj\sim\audio_rom.hex          ← 仿真用
```

然后 **重新综合 + 重新烧板**（`Program SRAM` 或 `Program Flash`）。

## 五、★ 4 段音效怎么和图片对应（一张图配一段音）

`play_scheduler.v` 里写的是：

```verilog
audio_seg <= {2'b00, want_id[1:0]};   // 段号 = 当前图片 id 的低 2 位
```

也就是**音效段号 = 当前显示的图片 id 取低 2 位**，不是"按事件触发"，
而是**一张图固定配一段音**，4 段音效按图片顺序循环。**放满 8 张图时**是这样：

| 图片（按文件名排序） | 第1张 | 第2张 | 第3张 | 第4张 | 第5张 | 第6张 | 第7张 | 第8张 |
|---|---|---|---|---|---|---|---|---|
| 图片 id | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| 播放音效段 | 段0 | 段1 | 段2 | 段3 | 段0 | 段1 | 段2 | 段3 |

> 即 **第 1/5 张同音、第 2/6 张同音、第 3/7 张同音、第 4/8 张同音**。

**4 段内置音效分别是什么**（不指定 wav 时，脚本自带）：

| 段 | 内容 | 听感 |
|---|---|---|
| 段 0 | 短提示音 | 1000Hz 单声"嘀" |
| 段 1 | 双声提示 | "嘀-嘀" |
| 段 2 | 上升扫频 | 400→2000Hz 上扬的一声 |
| 段 3 | 柔和铃声 | 880Hz 带泛音、指数衰减 |

**换图 = 换段**，音效跟着画面一起变。
应急时切到第 1 张图（`EMERG_ID = 0`）→ 同时切到**段 0** 的音效。

> 所以"想让某张图配哪段音"，调它的**文件名顺序**就行。
> 想确认换段真的生效，跑 `sim\tb_audio_player.v`（7 项检查里包含"换段生效"）。
