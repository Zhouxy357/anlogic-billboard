## 三、主线手册怎么读（`从零到上板操作手册.md`）

手册很大（6600+ 行），**不要从头读到尾**。第一遍只读 7 个部分：

| 章节 | 读什么 | 目的 |
|---|---|---|
| **第 0 节** | 这份手册怎么用 | 知道手册结构 |
| **第 1 节** | 最终效果 | 知道做出来是什么样 |
| **第 2 节** | 准备清单 | 检查软件、板子、卡都齐了没 |
| **第 4 节** | ★ 每个文件在哪个软件里执行 | 全文最重要的表之一 |
| **第 5 节** | ★ 每个代码"怎么跑一遍"速查总表 | 回答"每个代码在哪个软件怎么跑" |
| **第 6 节** | ★ 出了问题怎么调试（四级排查法） | **报错/上板不对时翻这节** |
| **第 7 节** | ★ 手把手：每个软件点哪里、敲什么 | 不知道点哪个菜单时翻这节 |

第 0~9 步是**每个模块的讲解 + 完整代码 + 「▶ 单独跑一遍」**，按信号流排好了：

```
第 0 步  打开工程        → 工程已建好，双击 bat 打开即可
第 2 步  key_debounce    → 最简单，从它建立"读模块"的手感（有独立仿真）
第 3 步  transition_ctrl → 淡入淡出状态机
第 4 步  banner_rom + osd_mixer → 字幕怎么叠到画面上
第 5 步  audio_rom + audio_player → 音频 + 跨时钟域握手（难点①，有独立仿真）
第 6 步  ebm_reader      → 私有容器解析（难点②，最长，有独立仿真）
第 7 步  play_scheduler  → 三层优先级调度，整个系统的"大脑"（难点③，有独立仿真）
第 8 步  seg_status      → 数码管，简单收尾
第 9 步  top_billboard   → 顶层，把所有模块连起来看（有顶层连线检查）
```

## 四、动手跑仿真（唯一入口：`仿真操作说明.md`）

```bash
cd /c/FPGA/billboard_prj/sim
bash run_iverilog.sh       # 全跑：2 项静态检查 + 19 个 tb = 21 项 / 313 条断言，免安装，推荐
bash run_iverilog.sh ebm   # 只跑某一个（key/audio/sched/ebm/spi/sd/frame/seg_595/... 共 19 个关键字）
python check_results.py    # 看中文结论表
```

跑出 **`通过 21 项，失败 0 项`** 就算过了 —— 这是"仿真正确"的唯一硬标准：
21 项全带 `PASS`，括号里 `n/n` 相等（如 `18/18`）。

> 19 个 tb 分别测什么、关键字怎么对应 → `代码运行速查卡.md` 第 2 节总表。

## 五、做素材 + 打开工程 + 上板

- **打开工程**：双击 `C:\FPGA\billboard_prj\scripts\1_open_project.bat`（工程已建好，不用重做）
- **做素材**（图片 → TF 卡 / 音频 → ROM）：手册第 10 步 + `tools\README.md`
- **写 TF 卡**：双击 `scripts\4_write_card.bat`（自动提权，输大写 `YES` 确认）；
  不想手动确认就双击 `scripts\4_write_card_auto.bat`（5 秒倒计时后全自动，含容器自检）

- **分辨率和状态**：看 `05-分辨率升级-720p改造说明.md`
- **核对我做过哪些** → `07-进度对照表.md`
