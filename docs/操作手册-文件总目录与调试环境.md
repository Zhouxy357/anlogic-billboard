## 0. 先记住：四个环境，用错工具就会报莫名其妙的错

| 代号 | 是什么 | 怎么进 | 管什么 |
|---|---|---|---|
| **【TD】** | 安路 TangDynasty 6.2.1（图形界面） | 双击 `scripts\1_open_project.bat` | 综合、布局布线、时序、烧录、看内部信号 |
| **【仿真】** | iverilog（IC Coder 自带）/ ModelSim | 命令行，见第 3.1 节 | 跑 testbench 验证模块逻辑 |
| **【GB】** | Git Bash（命令行黑窗口） | 右键 → Git Bash Here | 跑 `.sh` 脚本、拉起仿真器 |
| **【PY】** | Python 3（在 Git Bash 里敲 `python`） | 同上 | 生成 ROM 数据、生成容器、重建手册 |

**三条铁规矩**（背下来，能省 90% 的坑）：

1. `tb_*.v`（testbench）**绝对不要加进 TD**——TD 只综合电路，加了会编出一堆无用逻辑。
2. 两个 `.hex` 要放**多处**：工程根 / `src\rom\` / `src\hdl\` / `billboard_Runs\syn_1\` **这 4 处都要有**；
   **`audio_rom.hex` 还要在 `sim\` 再放一份**（共 5 处），`banner_rom.hex` 不需要 `sim\`。
   少了 → 只报 `CRITICAL-WARNING` 不报 ERROR，但 ROM 是空的 → **上板黑屏**。
3. 改了任何 `.v` → 先【仿真】跑绿 → 再【PY】重建手册 → 最后【TD】综合烧录。**绝不改完直接烧板子。**

## 2. ★ 按工具分类：每个文件该在哪个环境调

### 2.1 要在【TD】里调试的（综合 / 布线 / 烧录 / 看内部信号）

| 文件 | 在 TD 里干什么 |
|---|---|
| `billboard.al` | **打开它 = 打开整个工程** |
| `src\hdl\` 全部 10 个 `.v` | 被综合成电路；双击文件名可看代码 |
| `src\ip\` `src\support\` `src\include\` | 被顶层例化，随综合一起编译 |
| `src\constraints\pin.adc` | 绑管脚（HDMI/LED/按键/数码管） |
| 根目录 `audio_rom.hex` `banner_rom.hex` | `$readmemh` 读进 ROM |

**TD 里怎么调**（左侧 FPGA Flow 面板）：

```
双击 scripts\1_open_project.bat          ← 打开工程
  ↓
展开 Syn Opt → 双击 Read Design          ← 检查 36 源文件 + 1 约束能否一起编译（0 ERROR）
  ↓
双击 Syn Opt 整行 → 双击 Phy Opt 整行 → 双击 BitWriter   ← 综合→布线→出比特流
  ↓
Phy Opt 下的 Generate Bitstream 出 billboard_Runs\phy_1\billboard.bit → 烧录
```

- **看报告**：`Design Summary` → `Utilization Summary`（资源）/ `Timing Summary`（时序，WNS 应为正）
- **抓芯片内部信号**（在线逻辑分析仪）：`Tools → Debug Tools → ChipWatcher`
- **重跑某步**：右键 `syn_1` → `Reset Runs` → 再双击该步
- 出报错先看 Console 的 **Log Tree** 标签页（只列 Error + Warning）

### 6.4 ⚠️ 为什么"双击 bat 没反应"

**本机实测结论：多半是因为 TD 已经开着了。**

安路 TD 同一时刻只允许开一个实例。第二个实例被拉起来会立刻自己退出，
看起来就是"双击没反应"。

排查顺序：
1. `Ctrl+Shift+Esc` 打开任务管理器 → 看有没有 `td.exe`
2. **有** → 切到那个 TD 窗口看标题栏：是 `Anlogic TD 6.2.1 - C:/FPGA/billboard_prj - billboard` 就说明工程早开了，直接用
3. **想重新开** → 先把所有 `td.exe` 关掉，再双击 bat

另外两种情况也**不代表 bat 坏了**：
- 双击后黑窗口一闪就没 → 正常，启动命令已发出（想看细节就用 `1_open_project.bat`，它会 `pause` 停住）
- 提示"找不到文件" → 工程目录被移动/改名了，先确认 `C:\FPGA\billboard_prj` 还在
