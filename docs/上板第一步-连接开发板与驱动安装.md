# 上板第一步：连接开发板 + 驱动安装（AC201 / EG4S20BG256）

> 这份文档回答三个问题：**怎么连？怎么供电？驱动和烧录怎么走？**
>
> **★ 目标板：米联客 AC201（底板 AC201 + EG4S20BG256 核心板）。**
> 芯片与竞赛指定的 HX4S20C 是**同一颗**，代码通用，但**板子布局、数码管驱动、按键数量不同**。
> 所以本文不再照抄 HX4S20C 的接口图 —— 按下面"找这 4 样"的方式在实物上认，最可靠。

---

## 一、一句话结论

| 问题 | 答案 |
|---|---|
| **怎么连接** | 一根 **USB 线** 从电脑接到板上的**下载器接口（AL-LINK）**；板子按需接 **5V 电源** |
| **要不要外加电源** | **看板子**：AC201 底板一般有 **DC 5V 座**（圆孔），插 5V/1A 适配器最稳；没有 DC 座就靠 USB 供电 |
| **供电电压** | **5V**。板上 DC-DC 转 3.3V / 2.5V / 1.2V 给 FPGA。用充电头就选 **5V ≥1A** |

> AC201 的下载器是 **AL-LINK**（USB 接口），本机驱动已装好且过了微软 WHQL 签名，
> 插上就能被 TD 识别 —— 不需要"禁用驱动签名"那一套。

---

## 二、在板子上找这 4 样（比看接口图可靠）

| 要找什么 | 怎么认 | 本项目用不用 |
|---|---|---|
| **下载器接口** | 板上 USB 口，旁边丝印 **`AL-LINK`** / `JTAG` / `USB` | ★ **就插这个**（供电 + 下载） |
| **电源** | 圆孔 **DC 5V** 座，或 USB 供电；旁边有电源指示 LED | ★ 通电后**电源灯亮** |
| **HDMI 口** | 板上**只有一个** HDMI 座（丝印 `HDMI`） | ★ 显示器接它 |
| **TF / Micro SD 卡槽** | 金属卡槽，丝印 **`TF`** / `SD` / `J2`；AC201 的卡槽可能在**板背面** | ★ 插写好素材的卡 |

另外两个按键要认一下（工程只用到 2 个）：

| 按键 | 丝印 | 功能 |
|---|---|---|
| KEY0 | `K1` / `KEY0`（引脚 **F7**） | 手动切下一张 |
| KEY1 | `K2` / `KEY1`（引脚 **E7**） | 自动轮播 开/关 |
| KEY2 | `K3` / `KEY2`（引脚 **H14**） | **复位**（低有效，按下复位） |
| SW0 / SW1 | 8 位拨码的最右两位（**N14 / K12**） | 轮播周期 / 应急画面（拨一下 = 按一次） |

> **不要**把下载线插到网口旁边的 USB-UART 口（那是串口调试用的，不能烧 FPGA）。
> 认不准就插拔一次看设备管理器里有没有 `Anlogic AL-Link` 出现。

### 连接步骤（照着做）

1. **先断电**（拔掉电源 / 关电源开关）。
2. USB 线一端插电脑，一端插板上 **AL-LINK** 口。
   - 电脑端**优先插机身自带的 USB 口**；不要经过无源 USB 集线器。
3. 接 5V 电源（有 DC 座就插适配器），或确认 USB 已供电 → **电源灯亮**。
4. （烧录前）**先把 TF 卡插好**、HDMI 线接显示器、显示器选对输入源。

> ⚠ 插拔 USB / 卡时先断电；裸露金属针脚不要用手摸（静电会损坏芯片）。

## 三、驱动安装（换电脑 / 重装系统时看）

### 3.1 本机实测结论（2026-10-18）

| 检查项 | 结果 |
|---|---|
| 设备管理器 | **`Anlogic AL-Link`，状态 OK，无黄色感叹号** |
| 驱动 | `oem210.inf`（anlocyusb.inf，Anlogic 提供，1.2.3.20） |
| 签名 | **Microsoft Windows Hardware Compatibility Publisher（WHQL 认证）**，签名通过 |
| 内存完整性 | 已关闭（值 = 0） |

> 所以你**不需要**做"禁用驱动签名"那一套。网上教程针对的是老式
> `USB-JTAG-Cable`（Anlogic USB Cable v0.1），那个驱动没过 WHQL，才需要变通。

### 3.2 判定流程

1. 插 USB 线、通电。
2. 打开**设备管理器**，找 **`Anlogic AL-Link`**：
   - **有且无感叹号** → 直接烧录（本机状态）。
   - **有但带黄色感叹号** → 走 3.3 装驱动。
   - **完全没有** → 检查：是否插错口、是否通电、换根 USB 线。
3. 验证：TD → `Tools → BitWriter`，`Refresh` 后能显示 **`EG4S20BG256`** 即通。

### 3.3 装驱动（带黄色感叹号时）

1. 设备管理器右键带感叹号的 Anlogic 设备 → **更新驱动程序**。
2. 选 **"浏览我的电脑以查找驱动程序"**。
3. 浏览到 TD 安装目录下的 **`driver`** 文件夹：
   ```
   C:\Anlogic\TD_6.2.1_Engineer_6.2.168.116\driver
   ```
   勾选"**包括子文件夹**" → 下一步。里面分 `al-link\` 和 `dl-cable\` 两套，
   **AC201 用的是 `al-link\`**（Win10/11 选 win10 目录）。
4. 若弹"驱动程序未经认证" → 选"仍然继续安装"。

### 3.4 仍报感叹号（签名拦截）

**先做这个**：设置 → 隐私和安全性 → Windows 安全中心 → 设备安全性 →
内核隔离详细信息 → **内存完整性 = 关** → 重启。

**还不行**：临时禁用驱动签名（重启后失效）
设置 → 系统 → 恢复 → 高级启动 → 立即重新启动 → 疑难解答 → 高级选项 →
启动设置 → 重启 → 按 **`F7`**（笔记本可能 `Fn+F7`）→ 进系统后重插 USB。

> 这是临时办法。比赛期间优先用已过 WHQL 的 AL-Link 驱动，**不要去动 BIOS**。
> Win11 还要注意先关 BitLocker，避免触发恢复密钥。

## 四、TD 里验证识别 + 烧录

> TD 6.2.1 把老的 `Tools → Download` 改名成 **`BitWriter`**。
> 三种打开方式：`Tools → BitWriter` / 工具栏下载图标 / 直接跑
> `C:\Anlogic\TD_6.2.1_Engineer_6.2.168.116\bin\bw.exe`（不用打开工程，最快）。

BitWriter 窗口从上到下五块：

| 步骤 | 界面位置 | 做什么 |
|---|---|---|
| ① | **器件/下载器信息栏** | 点 **`Refresh`** → 显示 **`EG4S20BG256`** 且 `Debug Server` = **`AL-LINK`** 才算通 |
| ② | **文件选择栏** | 选 `C:\FPGA\billboard_prj\billboard_Runs\phy_1\billboard.bit` |
| ③ | **下载模式栏** | 选 `Program SRAM`（调试）或 `Program Flash`（固化），速率默认 **5MHz** |
| ④ | **控制/信息栏** | 点运行按钮 |
| ⑤ | **状态栏** | 看进度与结果 |

| 下载模式 | 效果 | 什么时候用 |
|---|---|---|
| **Program SRAM** | 烧到配置 RAM，**掉电即丢** | ★ **调试首选**，改一次烧一次，不损耗 Flash |
| **Program Flash** | 烧到板上 SPI Flash，**掉电不丢**，上电自动加载 | 演示 / 答辩 |

> ⚠ 用 `Program SRAM` 烧完**千万别断电**；要插拔 TF 卡就**先插好卡再烧**。
> 其余模式（Verify / Erase / SPIBIN / Dual Boot / Multi Boot）本项目用不到。

## 五、烧录前后的正确顺序（别白烧）

### 5.0 ★ 先花 30 秒确认 HDMI 硬件通路（强烈建议，别跳）

黑屏最烦的地方是**分不清是 HDMI 不通，还是数据没来**。所以先烧最小验证电路：

**`bit\1_hdmi_test_colorbar.bit`**

这个 bit 里只有 `50MHz → PLL → HDMI 核（核内自带彩条）→ PHY → 4 根 HDMI 引脚`，
**不碰 TF 卡、不碰 SDRAM、不含任何自研模块**。参数逐项照抄官方 AC201 参考实现。

| 烧完看到 | 结论 | 下一步 |
|---|---|---|
| **LED[3] 快闪 + 屏幕出彩色竖条** | HDMI 通路 100% 没问题 | 往下走，去准备 TF 卡素材 |
| LED[3] 快闪，但屏幕无信号/黑 | 问题在硬件侧 | 换 HDMI 线；换显示器输入源；确认显示器自动选源；确认插的是板上的 HDMI **OUT** |
| LED 全不亮或不闪 | FPGA 没配置成功 | 回第四节，检查 AL-LINK、供电、是否烧错文件 |

> 这一步能把排查范围直接砍掉一半。诊断工程源码在 `port_ac201\hdmi_test\`（含 README）。

### 5.1 正式工程的正确顺序

素材没准备好，烧了也是黑屏。正确顺序：

1. **先备 TF 卡素材**：图片放进 `assets\img\` → **双击 `scripts\4_write_card_auto.bat`**
   （全自动：打包 + 提权 + 写卡，只要在 UAC 点"是"，不用输 YES）；
2. 安全弹出读卡器，卡插回板子卡槽（AC201 可能在**背面**，插到底听到"咔"）；
3. HDMI 线接显示器，显示器选对输入源；
4. 再烧 **`bit\2_billboard_full.bit`**（`Program SRAM`）；
5. 按手册**第 13 步清单**逐项看现象。

> 只想先确认"板子活没活"：可以跳过第 1~2 步直接烧 —— **LED[3] 心跳**和数码管
> 不依赖 TF 卡；但**屏幕出图和声音必须有卡里的素材**。

### 5.2 烧完应该看到什么（按时间顺序）

| 时刻 | 板子 | 显示器 |
|---|---|---|
| 烧完/上电瞬间 | **LED3 开始闪**（3Hz 左右）= 芯片配置成功 | 无信号 / 黑 |
| 0.5 秒 | 数码管状态位显示 `S` | 黑 |
| 0.5 秒 | **LED0 亮** = SD 卡初始化成功 | 黑 |
| 1~3 秒 | 状态位 `0`→`1`→`3`→`4`→**`2`** | 切到 **1280×720@60**，从黑**淡入**第一张图 |
| 稳定后 | `A` `0` `8` `2` `灭` `灭`（模式A/第0张/共8张/显示中/无错） | 整屏图片 + **底部 32 行滚动字幕带** |
| 每 10 秒 | 状态位跳 `4`→`2` | 淡出→淡入下一张，**同时响一声短音效** |

> 上面这一整套流程 **2026-10-18 晚已在本板实跑通过**：
> 彩条诊断版出彩条 → 写卡后烧完整版 → **图片 + 滚动字幕 + 声音同时正常**。
> 所以如果你卡在上表某一步，先怀疑"卡里的素材有没有真的写进去"
> （`write_card.log` 必须出现『写入完成』），而不是代码。

> 完整版（含"数码管镜像""全 8 代表空配置"等判读）见手册 **第 13 步 → 13-0 / 13-1 节**。

## 六、常见问题速查（AC201）

| 现象 | 原因 | 办法 |
|---|---|---|
| 设备管理器**没有** Anlogic 设备 | 插错口 / 没通电 / 线坏 | 换到 AL-LINK 口；确认电源灯亮；换线 |
| 电源灯不亮或忽明忽暗 | 供电不足 | 换 5V/1A 适配器或机箱后置 USB 口 |
| 有设备但带**黄色感叹号** | 驱动没装好 / 签名拦截 | 走 3.3 → 3.4 |
| BitWriter 里**识别不到芯片** | TD 在驱动装好之前就开了 | 关掉 TD 重开；别开多个实例 |
| 烧录报 License 错误 | license 过期 | 换竞赛包里的新 license（手册 6-3），本机到 2029-08-17 |
| **LED 全灭、数码管乱码** | bit 是给 HX4S20C 编的（引脚不对） | 用**本次重新综合的 AC201 版** `billboard.bit` |
| 烧完黑屏、但 LED[3] 在闪 | 卡没插好 / 卡里没有最新 `container.bin` | 重新写卡（`4_write_card.bat`），卡插到底 |
| 显示器**一直无信号** | HDMI 线/输入源；或 bit 不是 AC201 版 | 换线换输入源；确认烧的是 `phy_1\billboard.bit`（2026-10-18 之后生成的） |
| **数码管一直不变** | ★ **正常现象**，静态显示 | 只有**位 2（运行状态）**会变：0 等 SD → 1 读索引 → 2 显示中。会闪的是 **LED[3] 心跳** |
| 数码管**全 8** | 芯片空配置（程序没跑） | 重烧；`Program SRAM` 断电即丢，烧完别断电 |
| LED[3] 完全不闪 | 程序没跑起来 | 重烧，确认状态栏 `PROGRAM_SRAM success` |

> **AC201 数码管是 2 片 74HC595 串行驱动**：本工程用 `seg_595.v` 把 6 位段码/位选
> 转成 16bit 串行帧。**若上板发现数字左右顺序颠倒**，说明 595 的位选位序与板上接线相反，
> 把顶层 `seg_595` 例化里的 `.seg_sel_n ({2'b11, seg_sel_w})` 改成
> `{seg_sel_w, 2'b11}` 即可（一改就整体镜像，不用动其它代码）。

## 附：AC201 与本工程相关的引脚速查

| 信号 | 引脚 | 说明 |
|---|---|---|
| `clk` | **K14** | 板载 50MHz |
| `rst_n` | **H14** | KEY2，低有效 |
| `key1` / `key2` | **F7 / E7** | KEY0 / KEY1 |
| `sw[0]` / `sw[1]` | **N14 / K12** | 拨码，替代原 key3/key4 |
| `led[0..3]` | **M12 / R16 / R15 / T15** | **低电平点亮** |
| `seg_ser/sclk/rclk` | **R14 / T14 / R12** | 74HC595 三线 |
| `HDMI_CLK_P` / `D0..D2_P` | **B10 / D11 / C11 / F10** | LVDS33_E |
| `sd_ncs/dclk/mosi/miso` | **R2 / M2 / L3 / K6** | SPI 模式 TF 卡 |
